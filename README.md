# 🌳 Binary Tree - DSA Series

A collection of Binary Tree problems implemented in C++ as part of Data Structures & Algorithms (DSA) practice. This repository covers fundamental tree concepts frequently asked in coding interviews.

---

## 📌 Topics Covered

- Tree Traversals
  - Preorder Traversal
  - Inorder Traversal
  - Postorder Traversal
- Level Order Traversal (BFS)
- Maximum Depth of Binary Tree
- Diameter of Binary Tree
- Balanced Binary Tree Check
